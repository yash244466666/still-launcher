# AGENTS.md

The canonical, tool-agnostic instructions for this repository are in **[AGENT.md](AGENT.md)**.

- Claude Code: read [CLAUDE.md](CLAUDE.md) and the committed `.claude/` toolkit.
- Gemini CLI: read [GEMINI.md](GEMINI.md).
- Any other agent: start with [AGENT.md](AGENT.md), then `docs/ARCHITECTURE.md`.

Project-wide rules that apply regardless of tool:

- Keep the app offline: no `INTERNET`, analytics, ads or accounts.
- Do not add AI/assistant attribution to commits or pull requests.
- Do not copy code, assets, strings or branding from another launcher.
- Run tests, lint and a debug build before claiming a change is complete.
